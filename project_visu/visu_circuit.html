How to use

Pick a part from the Insert menu (or press its letter), then click the canvas to place it. Select parts with the Select tool; drag to move, double‑click to edit a value, right‑click to delete.

Wire crossings

Mid‑segment wire crossings do not connect by default. Place a Junction at the crossing point to force a connection.

Open circuits

Components in an open branch report exactly 0 A. Sub‑nanoamp residual currents from the internal solver conditioning are suppressed to zero, so opening a switch really does stop current everywhere downstream.

Short circuits

A red banner appears when the sim detects a shorted current source, a shorted voltage source, a singular matrix, or numerical overflow. Fixing the issue clears the banner.

History & branches

The timeline stores every recorded state. Its maximum length is set in Simulate → History limit… (presets include "unlimited"). When you press Go Live from a rewound position, the behavior is controlled by Simulate → Branch behavior…:

  • Auto-create (default): saves the current state as a new branch, then resumes.
  • Discard silently: throws away future history without saving.
  • Ask: prompts before discarding.

File → Save branch adds a manual snapshot. File → Load branch… shows the tree of branches; each row has Load, rename (✎), copy (⧉), and delete (✕) actions. Deleting a branch re‑parents its children to its parent so nothing is orphaned. Branches are included in exports.

New circuit clears the circuit and every saved branch.

Export / Import

File → Export circuit saves the complete app state (parts, wires, timeline, branches, view) to JSON. File → Import circuit restores it.
